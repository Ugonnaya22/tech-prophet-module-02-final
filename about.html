About This Blog

DevNotes Hub started as a personal study notebook to document lessons learned while building projects from scratch. Too many tutorials skip straight to shortcuts without explaining why the underlying markup matters.

Our goal is simple: publish readable, honest technical guides that anyone can follow—whether you are using a desktop browser, a mobile screen, or assistive technology.

Our Core Writing Principles

  • Write in plain, everyday language and explain technical terms clearly.
  • Test every code snippet against official web standards.
  • Treat accessibility as a baseline requirement, never an afterthought.
