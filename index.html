Quick Glossary

Semantic HTML
Choosing HTML elements based on the meaning of the content rather than how they look on screen.
Relative Path
A file link written relative to the current document's folder location.
WCAG
Web Content Accessibility Guidelines — international standards for making web content usable by everyone.
